* Consider the inputs stage of the recipe (meta/pipeline1.md): contrast local surprisal vs bayesian surprisal vs narrative departure on one input. Consider an input where each timestep is a 15-dim embedding made of 3 streams: narr1 (the main narrative) captured by features 1-5, narr2 by features 6-10, non-narr by features 11-15. Say the input is 100 timesteps long.
* Say that each stream has its own independent on/off markov chain, one step per timestep, so any number of streams can be on at once. Once on, a stream tends to stay on, and once off, to stay off: p(stay on), p(stay off) = .95, .8 for narr1, .93, .93 for narr2, .9, .95 for non-narr, so narr1 is mostly on, non-narr mostly off, and all flip rarely. narr1 starts on, the others off. A run has to last at least 4 timesteps before the stream can flip, so the story does not flicker. The script prints each stream's on and off times. Seed 0 gives narr1 4 flips, narr2 8, non-narr 8, never two streams at the same timestep; the number of streams on at a timestep is 0, 1, 2, 3 for 3, 39, 44, 14 timesteps.
* Say that narr1 is purple and narr2 green wherever they appear: their rows in the input matrix (shade = value; non-narr in greys) and their lines in the narrative departure panel. Local and bayesian surprisal are blue.
* Say that every stream shares one value (.7), so none reads as brighter than the others in the input matrix. While a stream is on, each of its 5 features is drawn from a gaussian over that value (sd .15), so features vary from timestep to timestep rather than sitting still; while off, its features are roughly 0 (noise, sd .05).
* Say that the three metrics are read off the input, not off which streams are on. For a stream, went_up(t) = sum over its 5 features of max(input(t) - input(t-1), 0), how much its features rose since the previous timestep; went_down is the same with the sign flipped. An event is a stretch of a stream being on. local_surprisal(t) = went_up summed over all three streams: big at every event start, i.e. any stream coming on, small elsewhere. For seed 0 at least 2.93 at event starts, at most 2.47 elsewhere.
* Say that bayesian_surprisal(t) = went_up summed over narr1 and narr2 only; non-narr coming on does not count. At least 2.87 at narrative event starts, at most 2.00 elsewhere.
* Say that narrative_departure(t) is one metric per narrative: that narrative's went_down. Big at every event end of its own narrative: at least 2.86 there, at most 1.22 elsewhere.

## Notes

* local surprisal says an event started, but not in which stream. Bayesian surprisal keeps only the narratives' event starts; each narrative departure marks the ends of its own narrative's events. So an event start shows up in local surprisal always, and in bayesian surprisal unless it is non-narr's.
* the gap between event starts and the rest is narrowest for local surprisal (2.47 vs 2.93), because it sums the wobble of every feature that is on, up to 15, while the other two sum 10 or 5.
