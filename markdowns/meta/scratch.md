To improve this, we lean on the fact that HPC is a cognitive map, in which nodes are connected to different nodes based on features. For example, I may be connected to Jalen & Saniya (roommate & Indian) but not them to each other. This allows us to compare incoming info to a prior distribution. Secondly, to cheaply store memories, one can now simply commit to memory when similarity drops; that an easy heuristic for when to complete the creation of a node; given that we want a sparse map (instead of adding every input as an individual node).
